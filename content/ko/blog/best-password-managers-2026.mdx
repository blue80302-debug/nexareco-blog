## 비밀번호 123456 아직도 쓰시나요

2025년 유출된 비밀번호 데이터를 보면, 여전히 가장 많이 쓰이는 비밀번호가 "123456"입니다. 사이트마다 다른 복잡한 비밀번호를 머릿속에 외우는 건 불가능합니다. 비밀번호 관리자는 이제 보안 의식이 있는 사람이라면 필수입니다. 5개 서비스를 3개월씩 쓰면서 보안 기능, 사용 편의성, 가격을 꼼꼼히 비교했습니다.

## 평가 기준

- **보안:** 암호화 방식, 제로 지식 아키텍처, 2FA 지원, 보안 감사 이력
- **사용 편의성:** 자동 완성 정확도, 브라우저 확장, 모바일 앱 품질
- **기능:** 비밀번호 생성기, 다크웹 모니터링, 파일 저장, 가족 공유
- **가격:** 무료 플랜 유무, 유료 가격 대비 기능

## TOP 5 비밀번호 관리자

### 1위: 1Password — 종합 최강

개인 플랜 월 $2.99 (연간 결제 시), 가족 플랜 월 $4.99 (최대 5명).

| 항목 | 1Password |
|------|-----------|
| 암호화 | AES-256 + SRP |
| 제로 지식 | 지원 |
| 2FA | TOTP, 보안 키 |
| 기기 수 제한 | 무제한 |
| 다크웹 모니터링 | Watchtower |
| 여행 모드 | 지원 |
| 무료 플랜 | 없음 (14일 체험) |

1Password의 가장 큰 강점은 "Secret Key" 시스템입니다. 마스터 비밀번호 외에 기기별 비밀 키가 추가되어, 마스터 비밀번호가 유출되더라도 다른 기기에서 접근이 불가능합니다.

Watchtower 기능은 저장된 비밀번호 중 유출된 것, 약한 것, 재사용된 것을 자동으로 찾아줍니다. 여행 모드는 국경 검문 시 특정 보관함을 기기에서 일시 삭제하는 독특한 기능인데, 해외 출장이 잦은 분들에게 유용합니다.

무료 플랜이 없다는 게 유일한 단점이지만, 월 2,99달러(약 4,000원)면 보안에 대한 투자로 충분히 가치 있습니다.

### 2위: Bitwarden — 오픈소스의 힘

무료 플랜 제공. 프리미엄 연간 $10, 가족 플랜 연간 $40 (최대 6명).

| 항목 | Bitwarden |
|------|-----------|
| 암호화 | AES-256 |
| 제로 지식 | 지원 |
| 2FA | TOTP, 보안 키, 이메일 |
| 기기 수 제한 | 무제한 |
| 다크웹 모니터링 | 프리미엄만 |
| 셀프 호스팅 | 지원 |
| 무료 플랜 | 핵심 기능 전부 포함 |

Bitwarden은 완전한 오픈소스입니다. 소스 코드가 공개되어 있어 누구나 보안을 검증할 수 있고, 정기적으로 외부 보안 감사도 받고 있습니다. 무료 플랜만으로도 비밀번호 무제한 저장, 모든 기기 동기화가 가능합니다.

연간 $10(약 13,000원)이면 프리미엄을 쓸 수 있는데, 이 가격에 TOTP 인증기, 다크웹 모니터링, 긴급 접근 기능까지 제공됩니다. 가성비로는 이 목록에서 단연 1위입니다.

셀프 호스팅을 지원한다는 것도 큰 장점입니다. 기업이나 개인 서버에 직접 설치해서 데이터를 완전히 자체 관리할 수 있습니다.

### 3위: Dashlane — 올인원 보안

프리미엄 월 $4.99 (연간 결제 시), 가족 플랜 월 $7.49 (최대 10명).

| 항목 | Dashlane |
|------|----------|
| 암호화 | AES-256 |
| 제로 지식 | 지원 |
| 2FA | TOTP, 보안 키 |
| 기기 수 제한 | 무제한 |
| VPN 포함 | 프리미엄에 포함 |
| 다크웹 모니터링 | 실시간 |
| 무료 플랜 | 25개 비밀번호, 1기기 |

Dashlane의 차별점은 VPN이 기본 포함된다는 겁니다. Hotspot Shield 기반 VPN이 프리미엄 플랜에 포함되어 있어, 별도 VPN을 구독하지 않아도 됩니다.

다크웹 모니터링도 가장 적극적입니다. 이메일 주소뿐 아니라 저장된 개인 정보 전반을 실시간으로 모니터링해서 유출 시 즉시 알려줍니다.

가족 플랜이 최대 10명까지 지원되는 점도 대가족이나 팀에게 좋습니다. 다만 다른 서비스 대비 가격이 높은 편이고, 무료 플랜은 25개 비밀번호에 1기기 제한이라 사실상 체험판입니다.

### 4위: NordPass — 심플한 선택

프리미엄 월 $1.49 (2년 약정), 가족 플랜 월 $2.79 (최대 6명).

| 항목 | NordPass |
|------|----------|
| 암호화 | XChaCha20 |
| 제로 지식 | 지원 |
| 2FA | TOTP, 보안 키 |
| 기기 수 제한 | 무제한 |
| 패스키 지원 | 지원 |
| 다크웹 모니터링 | 프리미엄만 |
| 무료 플랜 | 비밀번호 무제한, 1기기 |

NordVPN을 만든 Nord Security의 비밀번호 관리자입니다. AES-256 대신 XChaCha20 암호화를 쓰는데, 보안 수준은 동등하면서 속도가 더 빠릅니다.

UI가 깔끔하고 직관적이라 비밀번호 관리자를 처음 쓰는 분들에게 진입 장벽이 낮습니다. 패스키 지원도 빨리 도입한 편이라 미래 지향적입니다.

2년 약정 시 월 $1.49(약 2,000원)라는 파격적인 가격이 매력적입니다. 다만 1Password이나 Bitwarden에 비해 고급 기능이 부족한 편입니다.

### 5위: LastPass — 복귀를 노리는 베테랑

프리미엄 월 $3.00 (연간 결제 시), 가족 플랜 월 $4.00 (최대 6명).

| 항목 | LastPass |
|------|----------|
| 암호화 | AES-256 |
| 제로 지식 | 지원 |
| 2FA | TOTP, 보안 키 |
| 기기 수 제한 | 무제한 |
| 다크웹 모니터링 | 프리미엄만 |
| 보안 이슈 이력 | 2022~2023 대형 유출 |
| 무료 플랜 | 1기기 타입 제한 |

솔직하게 말하겠습니다. LastPass는 2022년과 2023년에 연속으로 대규모 보안 침해를 겪었습니다. 암호화된 보관함 데이터가 유출되면서 신뢰도가 크게 떨어졌습니다.

그 이후 보안 인프라를 대폭 개편했고, 독립 보안 감사도 다시 받고 있습니다. 기능적으로는 여전히 준수하지만, 보안 이력 때문에 순위를 낮게 뒀습니다. 비밀번호 관리자에서 가장 중요한 건 "신뢰"인데, 한 번 깨진 신뢰를 회복하려면 시간이 필요합니다.

## 결론: 상황별 추천

**종합 추천:** 1Password. 보안, 기능, 사용성 모두 빈틈이 없습니다.

**무료로 시작하고 싶다면:** Bitwarden. 무료 플랜만으로 충분히 실용적입니다.

**보안 + VPN 한 번에:** Dashlane. VPN까지 포함된 올인원을 원한다면.

**저렴하고 심플하게:** NordPass. 복잡한 기능 필요 없이 기본에 충실하려면.

**LastPass는?** 과거 보안 이슈가 신경 쓰인다면 다른 선택지가 많습니다. 이미 쓰고 있다면 마이그레이션을 검토해보세요.

비밀번호 관리자를 처음 도입하는 분들에게 한 가지 팁: 어떤 서비스를 선택하든, "쓰지 않는 것"보다는 낫습니다. 일단 하나 골라서 시작하세요.

디자인 툴 구독료가 매달 카드 명세서에 찍히는 걸 보다가 정리를 한번 해야겠다고 마음먹었습니다. 한동안 Figma, Sketch, Canva를 전부 결제해서 썼거든요. 같은 작업을 세 툴에서 돌려보니 "뭐가 제일 좋냐"는 질문이 얼마나 의미 없는지 알게 됐습니다. 세 툴은 같은 링에 서 있지 않았습니다.

먼저 밝혀둘 게 있습니다. 이 글을 쓰려고 최신 가격을 웹에서 다시 확인하려 했는데, 검색 도구가 막혀서 실시간 확인을 못 했습니다. 아래 가격은 각 서비스 공식 요금 페이지에서 제가 마지막으로 확인한 수치 기준이고, 환율이나 정책에 따라 달라질 수 있습니다. 결제 전에는 꼭 공식 페이지를 다시 보세요.

## 한눈에 보는 비교표

| 항목 | Figma | Sketch | Canva |
|---|---|---|---|
| 주 용도 | UI/UX, 프로토타입, 디자인 시스템 | macOS 기반 UI/아이콘 디자인 | SNS, 발표자료, 인쇄물, 영상 |
| 무료 플랜 | 있음 (파일 수 제한) | 없음 (체험판 제공) | 있음 (템플릿 일부 제한) |
| 유료 가격(대략, 연 결제) | Professional 풀 시트 월 $15~16 안팎 | Standard 에디터당 월 $10~12 안팎 | Pro 월 $10 안팎 (연 약 $120, 월 결제 시 약 $15) |
| 지원 환경 | 브라우저 + 데스크톱 앱 (Win/Mac/Linux) | Mac 앱이 핵심, 웹은 보기·피드백 중심 | 브라우저, 모바일 앱, 데스크톱 앱 |
| 실시간 공동 편집 | 매우 강함 | 가능하지만 Figma만큼 매끄럽지 않음 | 강함 (편집·댓글) |
| 프로토타이핑 | 강력 (인터랙션, 변수, 조건문) | 기본 수준 | 단순 애니메이션 수준 |
| 디자인 시스템 | 컴포넌트, 변수, Dev Mode | 심볼, 라이브러리 | 브랜드 키트 (제한적) |
| AI 기능 | 디자인 생성·보조 기능 확대 중 | 제한적 | 매직 스튜디오 등 풍부 |
| 러닝커브 | 중간 | 중간 | 매우 낮음 |
| 추천 대상 | 제품 디자이너, 개발자 협업팀 | Mac 전용 1인·소규모 디자이너 | 마케터, 소상공인, 비디자이너 |

참고로 Figma는 2025년에 시트 체계를 Full, Dev, Collab으로 나눴습니다. 그래서 "에디터 한 명당 얼마"로 단순 비교하기가 예전보다 까다롭습니다. 개발자가 Dev 시트만 필요한지, 디자인까지 건드리는지에 따라 팀 비용이 꽤 달라집니다.

## Figma: 협업이 필요하면 결국 여기로 옵니다

세 툴 중 제 작업 시간의 70% 이상을 차지한 건 Figma였습니다. 이유는 간단합니다. 링크 하나만 던지면 기획자, 개발자, 대표님까지 같은 화면을 보면서 의견을 남깁니다. 파일을 메일로 주고받던 시절을 생각하면 협업 방식이 완전히 달라졌습니다.

**써보니 좋았던 점**

- **Auto Layout과 컴포넌트**: 버튼 텍스트가 길어지면 알아서 늘어나고, 메인 컴포넌트를 고치면 전체가 바뀝니다. 화면이 50개를 넘어가는 프로젝트에서 이 차이가 엄청 큽니다.
- **변수(Variables)와 디자인 토큰**: 다크모드나 다국어 버전을 한 파일에서 관리할 수 있습니다.
- **Dev Mode**: 개발자가 CSS나 간격 값을 바로 복사해 갑니다. "여기 패딩 몇이에요?"라는 질문이 눈에 띄게 줄었습니다.
- **플러그인 생태계**: 아이콘, 목업, 더미 데이터까지 거의 다 있습니다.
- **플랫폼 무관**: 윈도우 개발자도, 맥 디자이너도 브라우저에서 똑같이 봅니다.

**아쉬웠던 점**

- 무료 플랜은 파일 수 제한이 있어서 본격적인 프로젝트에는 금방 한계가 옵니다.
- 시트 종류가 늘어나면서 요금 계산이 복잡해졌습니다. 팀이 커질수록 청구서가 부담스러워집니다.
- 페이지와 레이어가 수백 개로 불어난 큰 파일은 브라우저에서 눈에 띄게 무거워집니다. 저는 파일을 쪼개고 안 쓰는 페이지를 정리해서 버텼습니다.
- 인쇄물이나 일러스트 작업은 솔직히 어울리지 않습니다. 벡터 편집은 되지만 전문 일러스트 툴 느낌은 아닙니다.

## Sketch: 맥 사용자에게는 여전히 쾌적합니다

Sketch는 "UI 디자인 툴의 원조"입니다. 한때 업계 표준이었다가 Figma에 자리를 많이 내줬죠. 그런데 다시 써보니 Mac 네이티브 앱이라 그런지 반응 속도가 정말 빠릅니다. 큰 캔버스를 확대하고 축소할 때 느낌이 다릅니다.

**써보니 좋았던 점**

- **가벼운 네이티브 앱**: 로컬 파일 기반이라 인터넷이 불안정한 곳에서도 안정적입니다.
- **깔끔한 UI**: 필요한 기능만 있어서 군더더기가 적습니다. 처음 입문할 때 덜 어지럽습니다.
- **벡터 편집 감각**: 아이콘이나 작은 일러스트를 다듬을 때 손에 착 붙습니다.
- **가격**: 에디터 기준으로 Figma와 비슷하거나 약간 저렴합니다. 뷰어(보기·댓글)는 무료로 제공되는 구조라서 소규모 팀에는 나쁘지 않습니다.

**아쉬웠던 점**

- **Mac 전용**: 팀에 윈도우 사용자가 한 명만 있어도 편집 협업이 어색해집니다. 웹 앱으로 볼 수는 있지만 편집 중심은 아닙니다.
- **실시간 협업 체감**: 공동 편집이 되긴 하지만 Figma만큼 자연스럽지 않았습니다.
- **생태계 크기**: 플러그인이나 커뮤니티 템플릿이 Figma보다 적고, 새 자료도 Figma 위주로 올라옵니다.
- **프로토타이핑**: 간단한 화면 연결은 되지만 복잡한 인터랙션을 구현하긴 어렵습니다.
- **무료 플랜 없음**: 체험판만 있어서 "일단 한번 써보자" 하기에는 진입 장벽이 약간 있습니다.

## Canva: 디자이너가 아닌 사람에게는 압도적입니다

솔직히 처음에는 Canva를 "초보자용 장난감" 정도로 봤습니다. 쓰다 보니 생각이 바뀌었습니다. 인스타그램 카드뉴스, 발표 자료, 썸네일, 간단한 영상까지 템플릿에서 시작해 10분 만에 끝낼 수 있었습니다. Figma로 같은 걸 만들면 템플릿을 찾고 폰트를 맞추느라 훨씬 오래 걸립니다.

**써보니 좋았던 점**

- **템플릿과 소재 라이브러리**: 사진, 일러스트, 폰트, 영상 소스가 방대합니다. Pro에서는 프리미엄 소재를 쓸 수 있습니다.
- **배경 제거, 매직 리사이즈, AI 기능**: 한 번 만든 디자인을 여러 사이즈로 바꾸는 작업이 정말 편합니다.
- **브랜드 키트**: 로고와 색상, 폰트를 등록해 두면 팀원이 비슷한 톤으로 만들어 줍니다.
- **러닝커브**: 튜토리얼 없이도 바로 씁니다. 비디자이너 동료에게 넘겨도 문제가 없었습니다.
- **다양한 출력**: PDF, PNG, 영상 내보내기는 물론 인쇄 주문까지 연결됩니다.

**아쉬웠던 점**

- **정밀한 UI 작업은 한계**: Auto Layout 같은 반응형 구조, 컴포넌트 변형, 디자인 토큰은 Figma 수준이 아닙니다. 앱 화면을 Canva로 설계하는 건 추천하지 않습니다.
- **템플릿 비슷비슷함**: 템플릿을 그대로 쓰면 다른 사람 결과물과 겹치는 느낌이 납니다. 조금만 손을 대야 개성이 생깁니다.
- **개발자 핸드오프 없음**: 디자인을 코드로 넘기는 기능이 없습니다.
- **무료 플랜 제한**: 프리미엄 소재와 일부 AI 기능은 유료입니다.

## 가격만 놓고 보면?

세 가지가 모두 월 $10~16 수준의 개인 플랜이라 "누가 압도적으로 싸다"는 말은 어렵습니다. 대신 이렇게 정리했습니다.

- **혼자 쓴다면**: 무료 플랜 활용도는 Canva와 Figma가 높고, Sketch는 체험 후 유료입니다.
- **팀으로 쓴다면**: Figma는 Full/Dev/Collab 시트 구성에 따라 비용이 크게 달라지니 역할별로 계산해야 합니다. Canva Teams는 비디자이너가 많은 조직에서 가성비가 좋았습니다. Sketch는 에디터만 과금하는 구조라 소규모 Mac 팀에 괜찮습니다.
- **숨은 비용**: Canva는 프리미엄 소재 이용권, Figma는 플러그인과 폰트 라이선스, Sketch는 윈도우 사용자용 대체 환경 문제가 변수였습니다.

## 실제로 이렇게 나눠 쓰고 있습니다

| 작업 | 제가 고른 툴 | 이유 |
|---|---|---|
| 앱/웹 화면 설계, 디자인 시스템 | Figma | 협업, 컴포넌트, 개발자 핸드오프 |
| 아이콘, 단일 화면 시안 | Sketch (Mac에서만) | 가볍고 빠름 |
| 블로그 썸네일, 카드뉴스, 발표 자료 | Canva | 템플릿과 속도 |
| 클라이언트에게 시안 공유 | Figma | 링크 공유와 댓글 |
| 급한 홍보 이미지 | Canva | 10분 컷 |

## 결론: 이런 사람은 이걸 쓰세요

**Figma를 고르세요**
- UI/UX 디자이너 또는 이 직군을 준비 중인 사람
- 개발자, 기획자와 한 파일로 일하는 팀
- 윈도우와 맥이 섞여 있는 환경
- 디자인 시스템을 장기적으로 운영해야 하는 조직

**Sketch를 고르세요**
- 맥만 쓰는 1인 디자이너나 소규모 팀
- 오프라인 작업이 잦고 가벼운 네이티브 앱을 좋아하는 사람
- 이미 Sketch 파일과 라이브러리가 쌓여 있어서 이전 비용이 큰 사람

**Canva를 고르세요**
- 마케터, 소상공인, 크리에이터, 강사 등 디자인이 본업이 아닌 사람
- SNS 콘텐츠, 발표 자료, 포스터를 빠르게 찍어내야 하는 사람
- 디자이너 없이 팀 전체가 브랜드 톤을 맞춰야 하는 조직

한 가지만 고르라고 하면 저는 **처음 시작하는 사람이라면 Figma 무료 플랜**을 추천합니다. UI 디자인 직군은 Figma가 사실상 기본 언어입니다. 다만 직무가 디자이너가 아니라면 Canva가 시간을 훨씬 아껴줍니다. Sketch는 "Mac 환경 + 개인 작업 + 익숙한 사람"에게는 여전히 좋은 선택이지만, 새로 시작하는 사람에게 1순위로 권하기는 어렵습니다.

결국 이 셋은 경쟁 제품이라기보다 용도가 다른 도구입니다. 저처럼 Figma와 Canva를 함께 쓰는 조합이 가장 현실적이었고, 그만큼 구독료도 한 번쯤 점검해 볼 만합니다.

> 참고: 이 글의 요금과 기능 정보는 각 서비스 공식 요금 페이지에서 제가 마지막으로 확인한 내용입니다. 작성 시점에 웹 검색 도구가 작동하지 않아 최신 가격과 사용자 리뷰 수치를 다시 확인하지 못했습니다. 실제 결제 전에는 Figma, Sketch, Canva 공식 사이트에서 현재 가격과 플랜 구성을 확인하세요.

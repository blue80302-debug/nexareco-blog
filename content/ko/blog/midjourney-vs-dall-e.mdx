## 디자이너 친구한테 AI 그림 보여줬더니

작년에 Midjourney로 만든 판타지 풍경 이미지를 디자이너 친구한테 보여줬습니다. "이거 어디서 구매한 스톡 이미지야?"라는 반응이 돌아왔죠. 그때 확신했습니다. AI 이미지 생성이 진짜 쓸 만한 수준이 됐구나.

그로부터 6개월, Midjourney v6.1과 DALL-E 3를 번갈아 쓰면서 두 도구의 성격이 완전히 다르다는 걸 깨달았습니다. 결론부터 말하면, **예술적 감성이 필요하면 Midjourney, 정확한 묘사가 필요하면 DALL-E 3**입니다.

## 가격부터 비교하자

| 항목 | Midjourney | DALL-E 3 |
|------|-----------|----------|
| 기본 플랜 | $10/월 (Basic) | ChatGPT Plus $20/월에 포함 |
| 표준 플랜 | $30/월 (Standard) | API 종량제 (이미지당 $0.04~$0.08) |
| 프로 플랜 | $60/월 (Pro) | - |
| 무료 사용 | 불가 | ChatGPT 무료에서 제한적 사용 |
| 상업적 사용 | 유료 플랜 모두 가능 | 생성 이미지 상업 사용 가능 |

가격만 보면 DALL-E 3가 압도적으로 유리합니다. ChatGPT Plus 구독료 $20에 텍스트 AI까지 쓸 수 있으니까요. Midjourney는 이미지 생성만을 위해 별도 구독이 필요한데, Basic 플랜의 월 200장 제한은 좀 빡빡합니다. 저는 Standard 플랜($30)을 쓰는데, 15시간의 Fast GPU 시간이 주어져서 여유 있게 작업할 수 있습니다.

## 이미지 퀄리티: 감성 vs 정확성

여기서 두 도구의 성격이 확연히 갈립니다.

**Midjourney는 "예술가"입니다.** 같은 프롬프트를 넣어도 Midjourney가 만든 이미지는 뭔가 분위기가 있어요. 조명, 색감, 구도에서 사람이 의도적으로 연출한 것 같은 느낌이 납니다. 특히 풍경, 인물 초상화, 컨셉 아트 쪽에서 퀄리티가 압도적입니다. v6.1에서 손가락 표현도 많이 개선됐고, 피부 질감이나 머리카락 디테일이 놀라울 정도예요.

**DALL-E 3는 "실무자"입니다.** 프롬프트에 적은 내용을 최대한 정확하게 반영하려고 합니다. "빨간 모자를 쓴 고양이가 파란 자전거를 타는 장면"이라고 입력하면, 진짜 빨간 모자, 진짜 파란 자전거가 나옵니다. Midjourney는 가끔 자기만의 해석을 넣어서 모자 색이 바뀌기도 하거든요. 특히 DALL-E 3의 텍스트 렌더링은 확실히 한 수 위입니다. 이미지 안에 글자를 넣어야 할 때 DALL-E 3가 훨씬 정확합니다.

## 워크플로우: 디스코드 vs ChatGPT

사용 경험에서 가장 큰 차이는 워크플로우입니다.

Midjourney는 **디스코드 기반**입니다. 처음 접하면 좀 당황스럽습니다. 채팅방에서 `/imagine` 명령어를 치고, 생성된 4장 중에서 업스케일할 걸 고르고, 변형 버전을 다시 요청하고... 이 과정이 익숙해지면 오히려 빠르지만, 진입 장벽이 높은 건 사실입니다. 최근에 웹 알파 버전이 나와서 좀 나아졌지만, 아직 디스코드가 메인입니다.

DALL-E 3는 **ChatGPT 안에 통합**되어 있어서 훨씬 직관적입니다. 대화하듯이 "이 이미지에서 배경색을 바꿔줘"라고 하면 됩니다. 프롬프트 엔지니어링을 몰라도 자연어로 설명하면 ChatGPT가 알아서 최적화된 프롬프트를 만들어줍니다. 이게 초보자한테는 엄청난 장점이에요.

## 장단점 정리

### Midjourney

**장점:**
- 압도적인 미적 퀄리티, 특히 예술적/감성적 이미지
- 스타일 일관성이 뛰어남 (`--sref` 파라미터로 스타일 고정 가능)
- 커뮤니티가 활발해서 프롬프트 참고가 쉬움
- v6.1의 인물 표현력은 현존 최고 수준

**단점:**
- 디스코드 기반 워크플로우의 진입 장벽
- 텍스트 렌더링이 아직 불안정
- 프롬프트 정확도가 낮을 때가 있음 (자의적 해석)
- Basic 플랜 200장 제한은 금방 소진

### DALL-E 3

**장점:**
- ChatGPT 통합으로 쉬운 사용성
- 프롬프트를 자연어로 써도 잘 이해함
- 텍스트 렌더링 정확도 높음
- ChatGPT Plus에 포함되어 가성비 좋음

**단점:**
- 미적 퀄리티에서 Midjourney 대비 아쉬움
- 스타일 일관성 유지가 어려움
- 세밀한 파라미터 조절 불가
- 실사 느낌의 인물 이미지는 제한적

## 실제 사용 시나리오별 추천

**블로그 썸네일/SNS 콘텐츠:** DALL-E 3. 빠르게 만들 수 있고, 텍스트 삽입도 가능합니다.

**포트폴리오/아트워크:** Midjourney. 퀄리티 차이가 확실히 납니다.

**제품 목업/프레젠테이션:** DALL-E 3. 정확한 묘사가 중요한 비즈니스 용도에 적합합니다.

**게임/판타지 컨셉 아트:** Midjourney. 이 분야에서는 경쟁 상대가 없습니다.

## 최종 결론

**예술적 감성과 비주얼 퀄리티가 최우선이라면 Midjourney**를 선택하세요. 디스코드 워크플로우에 적응하는 데 하루이틀이면 충분하고, 그 이후로는 생성되는 이미지 퀄리티에 계속 감탄하게 됩니다.

**편리한 사용성과 정확한 프롬프트 반영이 중요하다면 DALL-E 3**입니다. 특히 이미 ChatGPT Plus를 쓰고 있다면 추가 비용 없이 바로 쓸 수 있다는 게 결정적입니다.

저는 두 개 다 쓰고 있습니다. 블로그 이미지는 DALL-E 3로 빠르게, 개인 프로젝트 아트워크는 Midjourney로 정성 들여 만듭니다. 두 도구의 성격이 확실히 다르기 때문에, 하나만 고르기보다는 용도에 맞게 사용하는 게 가장 현명한 선택이라고 생각합니다.

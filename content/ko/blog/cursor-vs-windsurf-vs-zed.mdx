AI 코드 에디터를 고를 때 "어느 쪽이 더 똑똑한가"만 따지면 답이 잘 안 나옵니다. 세 제품 모두 Claude, GPT 계열 같은 비슷한 모델을 쓸 수 있기 때문입니다. 실제로 갈리는 건 **에디터의 뼈대, 돈이 나가는 방식, 그리고 AI를 얼마나 앞세우느냐**입니다.

이 글은 2026년 11월 초까지 공개된 요금 페이지와 리뷰 사이트(CloudZero, ToolJunction, ComparEdge, Digital Applied 등)를 바탕으로 정리했습니다. 이 도구들은 요금제가 자주 바뀌니, 결제 전에 공식 가격 페이지를 한 번 더 확인하세요.

## 먼저 핵심 차이 3가지

1. **출신이 다릅니다.** Cursor는 VS Code 기반에 AI를 깊게 넣은 "AI 전용 IDE"입니다. Windsurf는 에이전트가 맥락을 따라가며 작업하는 흐름을 앞세웁니다. Zed는 처음부터 새로 만든 Rust 네이티브 에디터이고, AI는 그 위에 얹은 선택 기능입니다.
2. **과금 구조가 다릅니다.** Cursor는 등급이 여러 단계인 사용량 풀 방식입니다. Zed는 에디터는 무료이고 AI 토큰에만 비용이 붙습니다. Windsurf는 이번 조사에서 최신 요금표를 확인하지 못했습니다(아래에서 설명합니다).
3. **생태계와 속도의 교환이 다릅니다.** VS Code 확장을 그대로 쓸 수 있는 쪽(Cursor 계열)과, 확장 호환을 포기하고 속도와 가벼움을 택한 쪽(Zed)이 갈립니다.

이제 하나씩 보겠습니다.

## 차이 ① 에디터의 뼈대: "VS Code 사본" vs "처음부터 새로"

### Cursor: 익숙함 위에 AI를 깊게 얹은 방식
Cursor는 VS Code 사용자가 설정과 확장을 거의 그대로 가져와 쓰기 쉬운 구조입니다. 그래서 학습 비용이 낮고, 에이전트가 여러 파일을 고치는 기능이 가장 성숙한 편으로 평가받습니다. Zed를 다룬 리뷰들이 Zed의 약점으로 "내장 에이전트가 Cursor보다 덜 강력하다"는 점을 꼽는 것도 같은 맥락입니다(ReviewRamble).

### Windsurf: 에이전트 흐름이 중심
Windsurf도 VS Code 계열의 AI IDE입니다. 코드베이스 맥락을 따라가며 여러 단계를 처리하는 Cascade 에이전트가 간판 기능으로 알려져 있습니다. 다만 이 글을 쓰며 Windsurf의 최신 요금표와 벤치마크 자료는 검색으로 확보하지 못했습니다. 그래서 Windsurf는 구체적인 수치를 단정하지 않고, 아래에서 "확인할 항목"으로 정리했습니다.

### Zed: 속도를 위해 호환성을 포기
Zed는 Atom을 만든 Nathan Sobo 팀이 Rust로 만든 GPU 가속 에디터입니다(ThePlanetTools). ComparEdge는 Pro의 핵심 가치를 "120fps급으로 반응하는 에디터"라고 설명합니다. 여기에 실시간 협업(멀티플레이어)이 기본으로 들어 있고, Windows 네이티브 지원은 2025년 10월 15일에 나왔습니다. Wikipedia 기준으로 2026년 10월 중순에 안정 버전 1.24.2가 나왔을 만큼 개발 속도도 빠릅니다.

대신 치르는 비용도 분명합니다. 여러 리뷰가 공통으로 꼽는 약점은 **VS Code 확장을 지원하지 않는다**는 점입니다. 쓰던 확장이 많은 분에게는 여기서 이미 결론이 갈릴 수 있습니다.

## 차이 ② 돈이 나가는 방식: 정액처럼 보이지만 사실은 "사용량 게임"

세 도구 모두 "월 얼마"로 보이지만, 실제 지출은 모델 사용량에 크게 좌우됩니다.

| 항목 | Cursor | Zed | Windsurf |
|---|---|---|---|
| 무료 | Hobby | Personal(수락된 엣지 예측 월 2,000회, 자체 API 키·외부 에이전트 가능) | 무료 플랜 존재 여부는 공식 페이지 확인 필요 |
| 개인 유료 | Pro $20 / Pro+ $60 / Ultra $200 | Pro $10 | 공식 페이지 확인 필요 |
| 팀 | Teams $40/인 (Premium 좌석 $120) | Business $30/인 | 공식 페이지 확인 필요 |
| 초과분 | 사용량 풀 초과 시 온디맨드 과금 | API 정가 + 10% | – |

### Cursor: 등급이 가장 세분화됨
CloudZero의 정리에 따르면 Cursor는 Hobby 무료, Pro $20, Pro+ $60, Ultra $200 구조입니다. 연간 결제 시 약 20% 할인이 붙습니다. Pro의 포함 사용량은 대략 가격과 비슷한 수준(약 $20어치)이고, Pro+는 약 3배, Ultra는 약 20배의 풀을 줍니다.

주의할 점이 하나 있습니다. 같은 자료에 따르면 **2026년 8월부터는 Auto 모드도 사용량으로 차감**됩니다. "Auto만 쓰면 부담 없다"던 계산이 달라진 셈입니다. 에이전트를 하루 종일 돌리는 사람이라면 Pro $20으로 끝나지 않고 Pro+나 Ultra로 올라갈 가능성이 큽니다.

### Zed: 에디터는 공짜, AI만 유료
Zed의 구조는 단순합니다. 에디터는 무료 오픈소스이고, 요금제가 값을 매기는 대상은 AI 계층입니다(YixScout).

- **Personal ($0):** 수락된 엣지 예측 월 2,000회. 자체 API 키(BYOK)나 Claude Agent, Codex CLI 같은 외부 에이전트, Ollama 등 로컬 모델을 무제한으로 쓸 수 있습니다.
- **Pro ($10/월):** 엣지 예측 무제한, 토큰 $5 포함. 초과분은 API 정가에 10%를 더해 월말 또는 추가 $10마다 청구되고, 지출 한도를 직접 정할 수 있습니다.
- **Business ($30/인):** 조직 단위 모델 정책과 데이터 거버넌스용입니다.

ComparEdge의 계산이 이해하기 쉽습니다. 한 달에 호스팅 토큰을 $50어치 쓰면 $55에 시트 비용 $10이 더해집니다. 10% 마진은 다른 도구의 마크업보다 작다는 평가입니다. 반대로 Pro에 포함된 토큰 $5는 최신 프런티어 모델 앞에서는 금방 소진되므로, Digital Applied의 표현대로 "AI 사용권보다는 엣지 예측 구독에 가깝다"고 보는 편이 정확합니다. 무료 체험 조건은 자료마다 다릅니다. 최신 자료(Digital Applied)는 14일에 $5 상당의 특정 모델만 제공한다고 하고, 이전 자료는 $20 크레딧이라고 합니다. 가입 전에 확인하세요. 인증된 대학의 학생이라면 Pro를 1년 무료로 쓸 수 있다는 정보도 있습니다.

### Windsurf: 가격은 직접 확인하세요
Windsurf는 이번 조사에서 최신 요금표를 확인하지 못했습니다. 틀린 숫자를 적느니 비워 두는 편이 낫다고 판단했습니다. 비교할 때는 아래 세 가지를 확인하세요.

- 월 포함 사용량의 단위가 크레딧인지 달러 환산 쿼터인지
- 한도를 넘으면 자동 과금되는지, 멈추는지
- 자체 모델을 쓸 때와 외부 프런티어 모델을 쓸 때 차감 속도가 얼마나 다른지

## 차이 ③ AI를 대하는 철학: "중심" vs "선택"

Cursor와 Windsurf는 AI가 제품의 중심입니다. 에디터를 열면 에이전트에게 일을 맡기는 흐름이 기본입니다. Zed는 반대로 AI를 선택 옵션으로 둡니다. ToolJunction은 Zed를 이렇게 요약합니다. Agent Client Protocol(ACP)이라는 개방형 규격 덕분에 특정 업체에 묶이지 않고, 가격도 Cursor보다 저렴하며 에이전트 기능도 훌륭하다는 평가입니다(4.5/5, AI 코드 에이전트 20개 중 8위).

이 철학 차이는 실무에서 이런 모습으로 나타납니다.

- 이미 Anthropic, OpenAI, GitHub 구독이 있다면 Zed에서 그 에이전트를 Personal 요금제로 돌릴 수 있습니다. Digital Applied는 이것이 외부 에이전트 전략이 사용자에게 이득이 되는 지점이라고 짚습니다.
- Cursor는 반대로 에디터 안에서 모델 접근과 청구까지 한 번에 해결해 줍니다. 대신 그 사용량 풀 안에 갇힙니다.
- 엔터프라이즈 쪽은 Zed가 아직 약합니다. ReviewRamble에 따르면 Business 플랜에 SSO, SAML, SCIM이 아직 없습니다.

## 장단점 한눈에

**Cursor**
- 장점: 익숙한 VS Code 환경, 성숙한 에이전트 기능, 월 $20부터 $200까지 사용량에 맞춘 단계 선택
- 단점: Auto 모드까지 사용량이 차감되어 비용 예측이 어려움, 헤비 유저는 상위 플랜으로 밀려날 수 있음

**Windsurf**
- 장점: 에이전트가 맥락을 따라가는 흐름 중심 설계
- 단점: 이번 조사에서 최신 가격과 한도를 검증하지 못함. 결제 전 확인 필수

**Zed**
- 장점: 네이티브 속도, 무료 Personal, Pro $10, 초과분 마진 10%, 외부 에이전트와 로컬 모델 지원, 실시간 협업
- 단점: VS Code 확장 불가, 내장 에이전트는 Cursor보다 약하다는 평가, Pro 포함 토큰이 적음, Business 보안 기능 부족

## 그래서 누구에게 무엇이 맞을까

- **"에이전트에게 큰 작업을 맡기고 싶고, VS Code에서 옮기고 싶지 않다"** → Cursor. 월 $20으로 시작하되, 사용량 대시보드를 첫 달에 꼭 확인하세요.
- **"이미 Claude나 Codex 구독이 있고, 에디터는 가볍고 빨랐으면 좋겠다"** → Zed. Personal 무료로 시작해서, 엣지 예측이 모자라면 $10 Pro로 올리면 됩니다.
- **"에이전트 흐름이 중심인 IDE를 비교해 보고 싶다"** → Windsurf를 후보에 넣되, 공식 요금표를 확인한 뒤 Cursor Pro와 같은 조건으로 따져 보세요.
- **"팀 보안(SSO 등)이 필수다"** → 현재 자료로는 Zed Business가 아직 부족하니 Cursor Teams나 다른 엔터프라이즈 옵션을 먼저 보세요.

세 도구 모두 무료로 시작할 수 있거나 체험판이 있습니다. 사용 중인 프로젝트 하나를 같은 작업으로 돌려 보고, 한 주 동안 사용량 화면에 찍히는 숫자를 보세요. 광고 문구보다 그 숫자가 더 정확한 비교표가 됩니다.

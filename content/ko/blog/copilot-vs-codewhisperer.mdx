솔직히 먼저 말씀드릴 게 있어요. **지금은 "Amazon CodeWhisperer"라는 이름의 제품이 따로 없습니다.** 2024년 4월에 AWS가 CodeWhisperer를 Amazon Q Developer로 흡수했거든요. 그런데 아직도 "CodeWhisperer 쓰세요?"라고 묻는 분이 많아요. 그래서 이 글에서는 CodeWhisperer의 후신인 Amazon Q Developer를 기준으로 Copilot과 비교합니다. 이름만 바뀐 게 아니라 기능 범위도 많이 달라졌어요.

저는 백엔드 작업이 많습니다. 주로 TypeScript와 Python을 쓰고, 가끔 AWS 인프라 코드(CDK, Terraform)도 만져요. 몇 주 동안 VS Code와 JetBrains에서 두 도구를 번갈아 써봤고, 그 느낌에 공식 가격 정책과 공개된 자료를 겹쳐서 정리했습니다.

> ※ 가격과 사용 한도는 두 서비스 공식 가격 페이지에 공개된 내용을 기준으로 적었습니다. 글 쓰는 시점에 실시간으로 다시 확인하지는 못했어요. 두 서비스 모두 요금제를 자주 바꾸니 결제 전에 공식 페이지를 꼭 한 번 보세요.

## 한눈에 보는 비교표

| 항목 | GitHub Copilot | Amazon Q Developer (구 CodeWhisperer) |
|---|---|---|
| 무료 플랜 | 있음 (월 2,000회 코드 완성, 50회 채팅 수준) | 있음 (월 에이전트·채팅 요청 한도 제한) |
| 개인 유료 | Pro 월 $10 / Pro+ 월 $39 | Pro 월 $19 (사용자당) |
| 팀·기업 | Business 월 $19 / Enterprise 월 $39 (사용자당) | Pro 월 $19 (IAM Identity Center 연동) |
| 주요 IDE | VS Code, Visual Studio, JetBrains, Neovim, Xcode 등 | VS Code, JetBrains, Visual Studio, Eclipse, CLI, AWS 콘솔 |
| 모델 | OpenAI, Anthropic, Google 모델 중 선택 | AWS 관리형 (Bedrock 기반), 모델 선택 폭은 좁음 |
| 에이전트 기능 | Agent mode, 코딩 에이전트(이슈 → PR) | 에이전트형 코딩, 코드 변환(Java 업그레이드 등) |
| 보안 스캔 | 코드 스캐닝·Autofix는 GitHub Advanced Security 쪽 | 보안 취약점 스캔 기본 내장 |
| AWS 특화 | 일반적인 수준 | 콘솔, 비용 분석, 리소스 질의 연동 |
| 오픈소스 유사 코드 | 코드 참조 필터 제공 | 참조 트래커로 라이선스 표시 |

## 가격: 개인이면 Copilot이 체감상 훨씬 가볍다

가격표를 보고 제일 먼저 든 생각은 "개인 개발자에게는 Copilot Pro가 너무 싼데?"였어요. Copilot Pro가 월 $10이고, Amazon Q Developer Pro는 월 $19입니다. 두 배 가까이 차이가 나죠. 게다가 Copilot은 학생, 교사, 인기 오픈소스 메인테이너에게 Pro를 무료로 열어주는 정책이 있습니다. 이 조건에 해당하면 고민할 이유가 거의 없어요.

팀 요금제는 Copilot Business와 Q Developer Pro가 둘 다 월 $19 근처라서 가격 차이가 사라집니다. 이 구간에서는 가격보다 "우리 팀이 어떤 클라우드와 어떤 코드 호스팅을 쓰느냐"가 더 중요해요.

Copilot에는 주의할 점이 하나 있습니다. 최근 요금제에는 **프리미엄 요청(premium requests)** 개념이 있어요. 기본 모델은 넉넉하게 쓸 수 있지만, 상위 모델이나 에이전트 기능을 쓰면 월 할당량이 깎입니다. Pro는 월 300회 정도의 프리미엄 요청이 포함된 걸로 알고 있어요. 저는 에이전트 모드로 큰 리팩터링을 몇 번 돌렸더니 할당량이 생각보다 빨리 줄었습니다. 무한이라고 생각하고 쓰면 안 돼요. Q Developer도 에이전트 요청과 코드 변환에 월 한도가 있어서 사정은 비슷합니다.

## 자동완성 품질: 일상 코딩은 Copilot이 한 수 위

두 도구의 가장 기본적인 기능인 인라인 자동완성부터 비교해볼게요.

**Copilot**은 한 줄이 아니라 함수 전체를 제안하는 경우가 많아요. 주석으로 의도만 적어도 꽤 그럴듯한 구현이 나옵니다. 테스트 파일을 열어두면 같은 스타일로 다음 테스트 케이스를 이어서 만들어주는 점도 좋았어요. 제안 속도도 빨라서 흐름이 끊기지 않습니다. 한 가지 불만은 가끔 존재하지 않는 API를 자신 있게 제안한다는 거예요. 이건 모든 AI 도구가 갖고 있는 문제지만, 그래도 짚고 갑니다.

**Amazon Q Developer**는 AWS SDK(boto3, AWS SDK for JavaScript)를 쓰는 코드에서 확실히 강했습니다. S3, DynamoDB, Lambda 핸들러를 작성할 때 파라미터나 에러 처리 패턴이 정확하게 나오는 경우가 많았어요. 반대로 AWS와 상관없는 프론트엔드 코드나 일반 알고리즘에서는 제안이 보수적이고 길이도 짧았습니다. "좀 더 해줘도 되는데" 싶은 순간이 자주 있었어요.

참고로 GitHub는 2022년에 Copilot 사용자 실험 결과를 공개했습니다. 간단한 HTTP 서버 작업에서 Copilot을 쓴 그룹이 약 55% 더 빨리 끝냈다는 내용이에요. AWS도 CodeWhisperer 시절에 비슷한 생산성 실험을 공개했는데, 과제 성공률과 속도가 모두 좋아졌다고 주장했습니다. 다만 둘 다 **벤더가 직접 만든 실험**입니다. 숫자 자체보다 "작업 유형에 따라 효과가 크게 다르다"는 정도로 받아들이는 게 안전해요. 제 체감상 반복적인 보일러플레이트에서 효과가 가장 컸고, 복잡한 도메인 로직에서는 별 차이가 없었습니다.

## 에이전트와 채팅: 선택지는 Copilot, 깊이는 Q Developer

요즘은 자동완성보다 에이전트 기능이 더 중요해졌죠.

Copilot의 **Agent mode**는 여러 파일을 수정하고 터미널 명령까지 실행하는 방식입니다. GitHub 이슈를 할당하면 코딩 에이전트가 브랜치를 만들고 PR까지 올려주는 흐름도 있어요. 가장 좋았던 건 모델을 고를 수 있다는 점입니다. 빠른 작업은 가벼운 모델로, 어려운 버그는 상위 모델로 돌리는 식이에요. 작업마다 모델을 바꿔보는 재미가 있고 결과 차이도 실제로 느껴집니다.

Q Developer는 모델 선택권이 거의 없는 대신 **AWS 맥락 이해**가 강점입니다. 콘솔에서 "이 Lambda가 왜 타임아웃 나는지" 같은 질문을 던지면 계정의 리소스를 참고해서 답해줘요. 비용 분석이나 IAM 권한 문제를 물어볼 때도 일반 챗봇보다 훨씬 실용적이었습니다. 또 하나 독특한 건 **코드 변환 기능**이에요. Java 8이나 11 프로젝트를 17로 올리는 작업을 자동화하는 기능인데, 레거시 Java를 가진 팀에게는 이게 결제 이유가 될 수 있어요. 저는 Java 레거시가 많지 않아서 깊게 써보진 못했습니다.

## 보안과 라이선스

Q Developer는 보안 스캔이 기본 기능으로 들어 있습니다. 코드에서 취약점을 찾아주고 수정 제안도 해줘요. CodeWhisperer 시절부터 내세우던 장점이죠. 무료 플랜에서도 스캔 횟수 제한은 있지만 쓸 수 있습니다. 오픈소스와 유사한 코드를 제안할 때 출처와 라이선스를 알려주는 참조 트래커도 있어요.

Copilot에도 공개 코드와 일치하는 제안을 걸러내는 필터가 있습니다. 보안 스캔과 자동 수정은 GitHub Advanced Security 같은 별도 제품과 엮이는 구조라서, 개인이 가볍게 쓰기에는 Q Developer가 더 한 번에 해결되는 느낌이었어요.

## 장단점 정리

**GitHub Copilot**

장점
- 개인 요금이 저렴하다 (Pro 월 $10, 학생·오픈소스는 무료 가능)
- 자동완성 품질과 속도가 안정적이다
- 여러 모델 중에서 골라 쓸 수 있다
- 지원 IDE가 넓다 (Neovim, Xcode까지)
- GitHub 이슈, PR, 리뷰와 자연스럽게 연결된다

단점
- 프리미엄 요청 한도를 신경 써야 한다
- AWS 특화 지식은 상대적으로 평범하다
- 상위 요금제(Pro+, Enterprise)는 금세 비싸진다

**Amazon Q Developer (구 CodeWhisperer)**

장점
- AWS SDK, 서비스 관련 제안이 정확하다
- 보안 스캔이 기본 내장이다
- Java 버전 업그레이드 같은 코드 변환 기능이 있다
- 콘솔과 CLI까지 쓸 수 있는 범위가 넓다
- 무료 플랜으로 충분히 체험할 수 있다

단점
- Pro가 월 $19로 개인에게는 부담이 된다
- AWS 외 영역에서는 제안이 소극적이다
- 모델 선택권이 거의 없다
- 이름이 CodeWhisperer에서 바뀌면서 문서와 자료가 혼재되어 헷갈린다

## 그래서 누구에게 뭘 추천하냐면

**Copilot을 추천하는 사람**
- 특정 클라우드에 묶이지 않고 이것저것 만드는 개인 개발자
- 학생이거나 오픈소스 메인테이너 (무료 혜택부터 확인하세요)
- 프론트엔드, 앱, 데이터 작업 등 AWS와 거리가 먼 업무가 많은 사람
- GitHub에서 이슈와 PR 중심으로 협업하는 팀

**Amazon Q Developer를 추천하는 사람**
- 하루 대부분을 AWS 위에서 일하는 사람 (Lambda, DynamoDB, CDK, IAM)
- 레거시 Java 업그레이드 작업이 쌓여 있는 팀
- 보안 스캔을 별도 도구 없이 같이 쓰고 싶은 팀
- 이미 AWS 계약과 IAM Identity Center로 계정 관리를 하는 회사

**둘 다 써볼 만한 사람**
- 두 서비스 모두 무료 플랜이 있으니 돈 안 내고 2주 정도 병행해보세요. 같은 프로젝트에서 같은 작업을 시켜보면 어느 쪽이 내 코드 스타일에 맞는지 금방 드러납니다.

## 제 최종 결론

한 개만 고르라면 저는 **Copilot**입니다. 개인 기준으로 가격이 낮고, 자동완성이 안정적이고, 모델을 골라 쓸 수 있고, 어떤 언어와 환경에서도 평균 이상은 해주기 때문이에요. 범용성에서는 Copilot이 앞선다고 봅니다.

다만 제 업무에서 AWS 인프라 코드나 서비스 연동 비중이 높아지는 시기에는 Q Developer 무료 플랜을 에디터에 같이 깔아두고 있어요. AWS 쪽 질문만큼은 거기서 답이 더 빨리 나오거든요. 둘을 경쟁 관계로만 볼 필요는 없고, **범용은 Copilot, AWS 특화는 Q Developer**로 역할을 나눠 쓰는 게 지금 제가 찾은 가장 현실적인 조합입니다.

마지막으로, AI 도구를 쓰더라도 제안 코드는 반드시 직접 읽고 테스트를 돌리세요. 어느 쪽이든 그럴듯하게 틀리는 경우가 분명히 있습니다.

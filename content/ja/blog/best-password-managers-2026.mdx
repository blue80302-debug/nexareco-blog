## ブラウザの保存機能、本当に安全ですか

Chromeの「パスワードを保存しますか？」に毎回「はい」を押している方、多いと思います。でも2025年だけでも、ブラウザに保存されたパスワードを狙うマルウェアが複数確認されています。専用のパスワードマネージャーはゼロ知識暗号化を採用していて、サービス提供者ですらあなたのパスワードを見ることができません。5つのサービスを3ヶ月ずつ使って、セキュリティ・使いやすさ・料金を比較しました。

## 評価基準

- **セキュリティ:** 暗号化方式、ゼロ知識アーキテクチャ、2FA対応、監査実績
- **使いやすさ:** 自動入力の精度、ブラウザ拡張、モバイルアプリの品質
- **機能:** パスワード生成、ダークウェブ監視、ファイル保存、家族共有
- **料金:** 無料プランの充実度、有料プランのコスパ

## TOP 5 パスワードマネージャー

### 1位：1Password — 総合力No.1

個人プラン月額$2.99（年払い、約450円）。ファミリープラン月額$4.99（最大5名）。

| 項目 | 1Password |
|------|-----------|
| 暗号化 | AES-256 + SRP |
| ゼロ知識 | 対応 |
| 2FA | TOTP、セキュリティキー |
| デバイス制限 | 無制限 |
| ダークウェブ監視 | Watchtower |
| トラベルモード | 対応 |
| 無料プラン | なし（14日間体験） |

1Passwordの最大の特徴は「Secret Key」です。マスターパスワードに加えてデバイス固有の秘密鍵が必要なので、万が一マスターパスワードが漏れても、別のデバイスからはアクセスできません。

Watchtower機能は、保存されたパスワードの中で漏洩・脆弱・再利用されているものを自動検出します。トラベルモードは、海外渡航時に特定の保管庫をデバイスから一時削除する機能で、入国審査でデバイス検査がある国では重宝します。

無料プランがないのが唯一のデメリットですが、年間約5,400円でこのセキュリティレベルなら十分な投資です。

### 2位：Bitwarden — オープンソースの安心感

無料プランあり。プレミアム年額$10（約1,500円）。ファミリー年額$40（最大6名）。

| 項目 | Bitwarden |
|------|-----------|
| 暗号化 | AES-256 |
| ゼロ知識 | 対応 |
| 2FA | TOTP、セキュリティキー、メール |
| デバイス制限 | 無制限 |
| ダークウェブ監視 | プレミアムのみ |
| セルフホスティング | 対応 |
| 無料プラン | コア機能すべて利用可 |

Bitwardenは完全オープンソースです。ソースコードが公開されているため、誰でもセキュリティを検証できますし、定期的に外部監査も受けています。無料プランでもパスワード無制限・全デバイス同期が可能で、他社の有料プランより充実しています。

プレミアムが年額$10（約1,500円）という価格は驚異的です。TOTP認証機能、ダークウェブ監視、緊急アクセス機能まで付いてこの価格です。

セルフホスティングに対応しているのも大きなポイントです。自社サーバーにインストールして、データを完全に自分で管理できます。UIは1Passwordほど洗練されていませんが、機能面では申し分ありません。

### 3位：Dashlane — オールインワンのセキュリティ

プレミアム月額$4.99（年払い、約750円）。ファミリー月額$7.49（最大10名）。

| 項目 | Dashlane |
|------|----------|
| 暗号化 | AES-256 |
| ゼロ知識 | 対応 |
| 2FA | TOTP、セキュリティキー |
| デバイス制限 | 無制限 |
| VPN内蔵 | プレミアムに付属 |
| ダークウェブ監視 | リアルタイム |
| 無料プラン | 25個まで、1デバイス |

Dashlaneの一番の特徴は、VPNがプレミアムプランに含まれていることです。Hotspot Shield製のVPNが追加料金なしで使えるので、別途VPNを契約する必要がありません。

ダークウェブ監視は今回テストした中で最も積極的でした。メールアドレスだけでなく、保存された個人情報全般をリアルタイムで監視してくれます。

ファミリープランが最大10名対応なのも、大家族やチームには嬉しいポイントです。ただし価格は今回のリストで最も高く、無料プランは25個・1デバイスなので実質的に体験版です。

### 4位：NordPass — シンプルで安い

プレミアム月額$1.49（2年契約、約220円）。ファミリー月額$2.79（最大6名）。

| 項目 | NordPass |
|------|----------|
| 暗号化 | XChaCha20 |
| ゼロ知識 | 対応 |
| 2FA | TOTP、セキュリティキー |
| デバイス制限 | 無制限 |
| パスキー対応 | 対応 |
| ダークウェブ監視 | プレミアムのみ |
| 無料プラン | パスワード無制限、1デバイス |

NordVPNを手がけるNord Securityのパスワードマネージャーです。業界標準のAES-256ではなくXChaCha20暗号化を採用していますが、セキュリティレベルは同等で、ハードウェアAES非対応デバイスでは高速に動作します。

UIがすっきりしていて直感的なので、パスワードマネージャー初心者には最も入りやすいサービスです。パスキー対応も早期に実装済みで、パスワードレス認証の時代を見据えています。

2年契約で月額$1.49（約220円）は、このリストで最安です。ただし1Passwordのような高度な機能は不足しています。

### 5位：LastPass — 信頼回復に挑戦中

プレミアム月額$3.00（年払い、約450円）。ファミリー月額$4.00（最大6名）。

| 項目 | LastPass |
|------|----------|
| 暗号化 | AES-256 |
| ゼロ知識 | 対応 |
| 2FA | TOTP、セキュリティキー |
| デバイス制限 | 無制限 |
| ダークウェブ監視 | プレミアムのみ |
| セキュリティ事故歴 | 2022〜2023年に大規模漏洩 |
| 無料プラン | 1デバイスタイプ制限 |

率直に言います。LastPassは2022年と2023年に連続して大規模なセキュリティ侵害を受けました。暗号化された保管庫データが流出し、サービスの信頼性が大きく損なわれました。

その後、セキュリティ基盤を大幅に刷新し、独立した監査も再度受けています。機能面はまだ十分に使えるレベルですが、パスワードマネージャーで最も大切な「信頼」が傷ついた事実は残ります。すでにLastPassを使っている方は、上記の代替サービスへの移行を検討してみてください。

## 結論：用途別おすすめ

**総合おすすめ：** 1Password。セキュリティ・機能・使いやすさ、すべてにおいて隙がありません。

**無料で始めたいなら：** Bitwarden。無料プランだけで十分実用的です。

**セキュリティ＋VPNをまとめたい：** Dashlane。VPN込みのオールインワンを求めるなら。

**とにかく安く済ませたい：** NordPass。シンプルで安い、基本に忠実なサービスです。

**LastPassは？** 過去のセキュリティ事故が気になるなら、他の選択肢が豊富にあります。移行ツールも各社揃っているので、乗り換えは簡単です。

最後に一つだけ。どのサービスを選んでも、「使わない」よりは確実に安全です。まずは一つ選んで、今日から使い始めてください。

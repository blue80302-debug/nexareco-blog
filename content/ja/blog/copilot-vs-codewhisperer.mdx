最初に大事な点をお伝えします。「Amazon CodeWhisperer」という名前のサービスは、今はもう存在しません。

2024年4月にAmazon Q Developerへ統合されました。料金はCodeWhisperer Professionalの月額19ドルのまま引き継がれています(usagepricing.comの整理より)。さらに2026年5月、AWSは新規サインアップを止めました。AWS公式のDevOpsブログによると、Q DeveloperのIDEプラグインと有料サブスクリプションは2027年4月30日にサポート終了です。後継はKiroになります。

そこで今回は、次の2つを同時に見ることにしました。

- 比較として今も意味のある「CodeWhisperer系譜(=Q Developer)」の実力
- 現在進行形で進化しているGitHub Copilot

価格、スペック、第三者のレビューや調査を調べ直しました。そこに自分のコーディング感覚を重ねて書いていきます。

## まず結論から

先に結論を書きます。

- **これから新しくAI補完ツールを選ぶ人は、GitHub Copilotの一択です。** Q Developerは新規で契約できないので、選択肢に入りません。
- **すでにQ DeveloperのProを使っているAWS中心のチームは、移行期限(2027年4月30日)までは使い続けて問題ありません。** ただし並行してKiroか別ツールの検証は始めておくべきです。

「どっちも良いですよ」とぼかす記事も多いのですが、2026年10月時点ではこう言い切るのが誠実だと思っています。

## スペック・価格の比較表

| 項目 | GitHub Copilot | Amazon Q Developer(旧CodeWhisperer) |
|---|---|---|
| 新規契約 | 可能 | 不可(2026/5/15に新規受付終了) |
| 無料枠 | 月2,000回のコード補完(Free) | エージェント系リクエスト月50回 |
| 個人向け有料 | Pro 月10ドル / Pro+ 月39ドル / Max 月100ドル | Pro 月19ドル(ユーザー単位) |
| 法人向け | Business 月19ドル / Enterprise 月39ドル(1席あたり) | Proのみ(IAM Identity Center経由で管理) |
| 課金モデル | 2026年6月からAIクレジット制(1クレジット=0.01ドル)。Proは月15ドル分、Pro+は70ドル分、Maxは200ドル分 | 月約1,000リクエストが目安。超過分の追加購入は不可(usagepricing.comより) |
| 対応IDE | VS Code、JetBrains、Visual Studio、Xcode、Eclipse、Neovim | VS Code、JetBrains、Visual Studio、Eclipse(プレビュー) |
| 得意分野 | 汎用的なコーディング全般 | AWSリソース操作、Javaアップグレードなどのモダナイズ |
| セキュリティ | 脆弱パターンのフィルタ、コードスキャン | 脆弱性スキャンと修正提案を標準搭載 |
| IP補償 | Business以上で提供 | Proで提供(Freeにはなし) |
| 将来性 | 継続的に機能追加中 | 2027/4/30にIDEプラグインのサポート終了、Kiroへ移行 |

料金の出典は、eesel.ai、nocode.mba、fast.io、Superblocks、layer3labsなどの2026年版の解説記事です。この手の情報は変わりやすいので、契約前に必ず公式ページを確認してください。

個人的に面白いと思ったのは、Copilotが2026年6月に「使った分だけ」のクレジット制へ寄ったことです。「月額10ドルで使い放題」という分かりやすさは薄れました。エージェント機能をガンガン回す人は、Pro+やMaxを検討することになります。

## 実際の使い心地

### Copilot:迷ったらこれ、と言える安定感

私がまず感じるのは、**エディタの外に出なくていい**ことです。VS Codeでも、JetBrainsでも、Xcodeでも同じ感覚で補完が出てきます。複数のエディタを行き来する人にとって、これはかなり大きな利点です。

最近はインライン補完だけでなく、エージェントモード、プルリクのレビュー、CLIまで一通り揃っています。GitHubのIssueからPRまで一気通貫でつながるのも、普段GitHubで開発している人には気持ちいいところです。

弱点もあります。Augment Codeの検証記事では、認証サービスのリファクタリングで、編集中のファイルへの提案は速くて正確でした。一方で、その認証APIを使う他の3サービスへの影響を尋ねると、決済連携を壊しかねない提案が出たそうです。**リポジトリをまたぐ影響範囲の把握は、まだ人間がやるべき**ということです。これは私の感覚とも一致します。

### Q Developer:AWSが絡むと急に頼もしい

CodeWhispererの頃は補完専用の印象でした。InfoWorldのレビューによると、2023年時点では、チャットウィンドウもコード説明機能もありませんでした。Q Developerになってからは、チャットやエージェント機能に加え、AWSコンソールのエラー診断、Javaのバージョンアップ変換(無料枠で月1,000行)まで入っています。

**IAMポリシーの書き方、Lambdaの設定、CloudFormationまわりのつまずき**のように「AWSの文脈」が必要な場面では、汎用ツールより一段頼りになる、という評価が多いです。G2のユーザーレビューも同じ傾向です。AWS環境でのコンテキスト理解が強いという声が目立ちます。

反対に、AWS以外の普通のアプリ開発だと、特別な強みは感じにくいです。

## 数字で見る比較:実測データとユーザー評価

主観だけだと説得力がないので、第三者のデータも入れます。

**Faros AIの企業内バトル(エンジニア430人)**では、次の結果が出ています。

| 指標 | GitHub Copilot | Amazon Q |
|---|---|---|
| 提案の採用率(最終コードに残った割合) | 22% | 11% |
| 採用コードのうち、レビューで修正不要だった割合 | 89% | 修正が必要だった割合が67% |
| 利用定着 | Qの約2倍 | - |
| 開発者満足度 | Qより12%高い | - |
| 週あたりの時間削減 | Qより約3時間多い | - |

この調査では、Copilotが採用率でも定着率でも倍近い差をつけています。ただし、これは特定の企業環境での結果です。AWS中心の現場では違う結果になる可能性があります。そのまま万国共通の真理として受け取るのは危険です。

**G2のレビュー評価**は意外な結果でした。Q Developerが4.6/5(51件)、Copilotが4.4/5(396件)です。Qのほうが点数は高いのですが、母数が約8倍違うので、単純には比べられません。ただ「使っている人の満足度は低くない」とは言えそうです。

SelectHubのまとめでは、どちらにも「複雑で曖昧な課題では提案が不正確になりやすい」「出力は丁寧にレビューが必要」という共通の不満が挙がっています。ここはどのAIツールでも同じです。

## 良いところ・悪いところ

### GitHub Copilot

**良い点**
- 対応エディタが広く、環境を選ばない
- 月10ドルのProから始められ、無料枠もある
- Faros AIの調査でも採用率・定着率が高かった
- エージェント、PRレビュー、CLIと機能の進化が速い

**悪い点**
- 2026年6月からクレジット制になり、ヘビーに使うと月額の見通しが立てにくい
- リポジトリ横断の影響分析はまだ弱い
- 高性能モデルをフルに使いたいなら、Pro+(39ドル)以上が現実的

### Amazon Q Developer(旧CodeWhisperer)

**良い点**
- AWSのサービス、コンソール、エラー診断との相性が抜群
- 脆弱性スキャンとIP補償(Pro)が標準で付いてくる
- Javaのアップグレード支援など、モダナイズ系が強い

**悪い点**
- **新規契約ができない**(2026年5月15日に受付終了)
- 2027年4月30日にサポート終了。移行コストが確実に発生する
- Proの上限(月約1,000リクエスト)に達しても、追加購入できない
- 汎用的なコード補完では、Copilotに採用率で見劣りする

## こんな人にはこっち

**GitHub Copilotがおすすめな人**
- これから初めてAIコーディング支援を導入する人(個人でも法人でも)
- 言語やエディタが混在している人
- GitHubでIssue管理からPRまで回している人
- まず無料で試して、合えば月10ドルのProに上げたい人

**Q Developerを使い続けていい人**
- すでにProを契約しており、AWSのインフラ運用や構築がメイン業務の人
- Javaの古いバージョンからのアップグレード案件を抱えている人
- ただし、**2027年4月末までにKiroなどへ移る計画を立てておくこと**が前提です

**今から「CodeWhispererを試したい」人**
- 残念ながら、新規ではもう試せません。AWS寄りの体験が欲しければ、後継のKiroを見るのが近道です

## 最後に

「CodeWhisperer vs Copilot」という比較は、いつの間にか「終わった勝負」になっていました。CodeWhispererはQ Developerに変わり、そのQ Developerも新規受付を終えています。Copilotはエージェント時代に向けて走り続けています。

私の結論はシンプルです。**AWS案件の既存契約がある人以外は、Copilotで始めてください。** まずFreeで2,000回の補完を使い切るくらい触ってみて、足りなくなったらProに上げる。この順番がいちばん失敗しません。

最後に注意です。料金や仕様はこの数か月でも大きく変わっているので、契約前に公式ページで最新情報を必ず確認してください。
